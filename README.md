## Pages and tasks

| Page | Tasks | Functionality |
|---|---|---|
| `index.html` | 0–1 | Console logging, hello alert, variable types, arithmetic and string concatenation |
| `dom.html` | 2–4 | Change text, change styles, create and remove list items |

## Run locally

Open `index.html` in any modern web browser, then navigate between pages with the navbar. Press **F12 → Console** for Task 0 and Task 1 output. No npm, dependencies, backend or build steps are required.

## Deploy with GitHub Pages

1. Push all project files to a GitHub repository (e.g. `WEB_Assignment5`).
2. Open repository **Settings → Pages**.
3. Select **Deploy from a branch**, branch **main**, folder **/(root)** and save.
4. Wait for GitHub Pages to show the published website URL.
5. Submit the GitHub repository URL in Moodle before the deadline; demonstrate the published site during defense.

## Main JavaScript concepts

- `console.log`, `alert`, strings, numbers, booleans and arithmetic operators.
- `document.getElementById`, `textContent`, `style`, `createElement`, `appendChild`, `removeChild`.
- `addEventListener` for `click`, `mouseover`, `mouseout`, `keyup` and `submit`.
- Arrays with `push`, `filter`, and `forEach` for the To-Do app.

**Note:** To-Do tasks exist only in memory and will reset if the page is refreshed, as allowed by the assignment.
